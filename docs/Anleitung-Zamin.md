# Texte auf doktura.de selbst ändern – Anleitung für Zamin

## Einmalig vorher
Du brauchst ein **GitHub-Konto**, das Leon für das Projekt freigeschaltet hat.
Falls du noch keins hast: Leon Bescheid geben, er lädt dich ein. Die Einladung per E-Mail einmal annehmen.

## So änderst du einen Text

1. Öffne **https://doktura.de/admin** im Browser (am besten am Computer).
2. Klicke auf **„Mit GitHub anmelden“** (bzw. „Login with GitHub“).
   Beim ersten Mal fragt GitHub, ob du den Zugriff erlaubst → **Erlauben** (Authorize).
3. Links siehst du drei Bereiche:
   - **Startseite** – alle Texte der Startseite, von oben nach unten nummeriert (1 = ganz oben).
   - **Bilder** – dein Porträt, das runde Bild oben und das Vorschaubild für geteilte Links.
   - **Einstellungen** – Kontaktdaten, Termin-Link, Instagram, rechtliche Angaben.
4. Klicke auf den Abschnitt, den du ändern willst, z. B. **„9 · Häufige Fragen“**.
5. Ändere den Text direkt im Feld.
6. Oben rechts auf **„Speichern“** (Save) klicken.
7. Fertig. Nach **etwa 1–2 Minuten** ist die Änderung auf doktura.de zu sehen.
   (Falls nicht: Seite neu laden, ggf. mit Strg + F5.)

## Kleine Formatier-Tricks
- `*Wort*` → wird *kursiv*
- `[Linktext](/seite)` → wird ein Link
- Eine **leere Zeile** im Text → neuer Absatz
- Text in `[eckigen Klammern]` ohne Link → gilt als Platzhalter (noch auszufüllen) und erscheint **nicht** auf der Live-Seite. Sobald du die Klammern durch deinen Text ersetzt, ist er sichtbar.

## Bilder austauschen
1. Links auf **„Bilder“** → **„Fotos & Vorschaubild“** klicken.
2. Beim gewünschten Bild auf **„Ersetzen“** bzw. **„Hochladen“** klicken und das neue Foto wählen.
3. Beim Porträt die **Bildbeschreibung** kurz anpassen, falls nötig.
4. **Speichern** – nach 1–2 Minuten ist das neue Bild online.

Tipps: Das Bild muss nicht verkleinert werden, das macht die Seite selbst. Beim runden Bild am besten ein quadratisches Foto mit Gesicht in der Mitte nehmen. Das Vorschaubild für Links (WhatsApp, LinkedIn …) ideal im Format 1200 × 630 px.

## Listen (z. B. Fragen, Leistungen)
- **Neuer Eintrag:** unten in der Liste auf **„Hinzufügen“** (Add).
- **Löschen:** beim Eintrag auf das Papierkorb- bzw. ✕-Symbol.
- **Reihenfolge ändern:** Eintrag an den Punkten anfassen und verschieben.

## Bitte beachten
- **Rechtliche Angaben** (Firma, Erlaubnis, Registernummer, IHK) nur ändern, wenn sie wirklich geändert sind – sie stehen im Impressum und in der Erstinformation.
- Jede gespeicherte Änderung wird automatisch gesichert. Wenn etwas schiefgeht: **Leon Bescheid geben** – jede alte Version lässt sich wiederherstellen.
- Das Design der Seite lässt sich hier nicht ändern – das macht Leon.
